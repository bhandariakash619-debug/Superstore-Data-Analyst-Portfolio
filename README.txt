Superstore Data Analyst Portfolio

Project Overview

This portfolio analyzes Superstore sales and profitability data using SQL, Python, and Power BI. The goal is to identify business trends, evaluate performance, and generate actionable insights.

Tools and Technologies

- SQL — data analysis and business queries
- Python — Pandas, data cleaning, analysis, and Matplotlib visualizations
- Power BI — interactive dashboard, KPI cards, charts, slicers, and business insights
- Jupyter Notebook — Python analysis and documentation

Project Files

1. Superstore SQL Portfolio — SQL queries for business analysis.
2. Superstore_Python_Portfolio.ipynb — Python data analysis and visualizations.
3. Superstore_PowerBI_Portfolio.pbix — interactive Power BI report.

Key Findings

- Total sales were approximately 2.30 million.
- Total profit was approximately 286,241.
- Overall profit margin was approximately 12.47%.
- Technology was the leading category in sales and profit.
- The West region recorded the highest sales.
- Tables were the largest loss-making sub-category.
- Texas recorded the largest state-level loss.

Skills Demonstrated

Data cleaning, exploratory data analysis, SQL querying, business analysis, data visualization, KPI reporting, and insight generation.

Project Outcome

This project demonstrates an end-to-end data analysis workflow using SQL, Python, and Power BI to turn raw data into useful business insights.
